 🎮 GameMatch – Personalized Game Recommendation App
**Final Year Project 2024/25**

## 📖 Overview
GameMatch is a full-stack web application that helps users find video games tailored to their preferences. It filters and recommends games based on genre, platform, and release date, ranking them using a match percentage score.

Built with **React.js** and **Supabase**, it leverages modern authentication, real-time database features, and responsive UI components.

---

## 🚀 Features
- 🔐 User registration & login (Supabase Auth)
- 🎯 Save personalized preferences (genre, platform, release date)
- 🕹️ Filter games dynamically
- 📊 Match percentage scoring
- 🔄 Sort results by relevance
- 💾 Preferences stored in Supabase
- 📧 Email verification
- 🖥️ Clean, responsive design (React.js)
